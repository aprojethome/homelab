# Homelab Raspberry Pi 400

## Infrastructure Linux, Docker, DNS, Monitoring et VPN


## Objectif

Création d'un laboratoire informatique personnel permettant d'apprendre :

- Administration Linux
- Réseau TCP/IP
- DNS
- Docker
- Sécurité système
- Monitoring
- Supervision
- VPN
- Documentation technique


## Matériel

- Raspberry Pi 400
- Raspberry Pi OS Lite 64 bits
- Connexion Ethernet
- PC Windows administration

Services :

- Pi-hole (DNS et blocage publicités)
- Portainer (gestion Docker)
- Homepage (dashboard)
- Grafana (visualisation)
- Prometheus (métriques)
- Uptime Kuma (supervision)
- WireGuard (VPN)


## Objectif final

Créer une infrastructure personnelle fonctionnelle,
sécurisée et documentée comme un projet professionnel.
